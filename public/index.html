FAQ

Questions

Can a key work on more than one PC?

No. A key locks to the first device that runs it. Buyers can reset it on the key page (with a cooldown), and you can reset any key from the dashboard.

When does a timed key start?

On its first run. A 30-day key that sits unused for a week still gets all 30 days.

Do buyers need a new loader when I update?

No. Save your script in the dashboard and everyone gets the new version on their next run.

What does a player see if their key doesn't work?

A Roblox notification saying why: invalid, expired, banned (with your reason) or wrong device.

Can someone still steal my script?

Someone with a valid key who hooks the executor can capture it. No key system can fully stop that, so use an obfuscator too if your code must stay private.
